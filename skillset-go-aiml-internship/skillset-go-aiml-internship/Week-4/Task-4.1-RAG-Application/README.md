# Task 4.1 - RAG Application

## Objective
Build a Retrieval-Augmented Generation pipeline: ingest, chunk, embed, store vectors, retrieve, and generate grounded answers.

## Tools Used
- Python
- LangChain
- FAISS or Chroma
- An LLM API

## Work Completed

Choose a focused knowledge base (course notes, manuals, FAQs, policies, project docs)

 Load documents and pick a chunking strategy you can explain
 
 Create embeddings and store them with FAISS or Chroma
 
  Implement query retrieval and inspect the actual chunks returned for several questions
  
 Pass retrieved context to generation; ask the model to stay grounded in it
 
 Test easy, multi-part, and unanswerable (out-of-scope) questions
 
 Record good retrieval, poor retrieval, and unanswerable examples with notes on what you'd improve
