# Task 4.2 - Multi-Step Workflow in LangGraph

## Objective
Model an explicit multi-step workflow with state, nodes, edges and conditional routing -- no more complexity than the task needs.

## Tools Used
- Python
- LangGraph

## Work Completed
 Draw the workflow first: task, steps, decisions, expected outputs
 
 Define the state that needs to move between steps
 
 Create focused nodes (retrieve, analyze, validate, summarize, respond)
 
 Use edges and conditional logic to control the path
 
 Run normal and failure cases; inspect where the workflow branches
