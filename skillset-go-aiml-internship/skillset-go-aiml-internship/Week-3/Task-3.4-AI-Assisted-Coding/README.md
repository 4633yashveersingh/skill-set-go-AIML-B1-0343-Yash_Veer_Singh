# Task 3.4 - AI-Assisted Coding Task

## Objective
Use an AI coding assistant on a small bounded app while keeping engineering control: specify, review, test, correct, and document.

## Tools Used
- Python or JS (your choice)
- An AI coding assistant
- Git

## Work Completed
- [ ] Choose a small, bounded app (data utility, API-backed mini tool, simple dashboard)
- [ ] Write a short spec before asking the assistant for code
- [ ] Use AI to generate/improve pieces while keeping control of architecture and requirements
- [ ] Run the code and deliberately test invalid inputs and edge cases
- [ ] Review imports, error handling, security-sensitive logic, duplication, assumptions
- [ ] Correct the implementation and keep short audit notes of important changes

## Deliverables
- The working application plus short audit notes: what AI suggested, what you accepted, what you changed and why

## Key Learnings
Write 3-5 points describing what you learned.
