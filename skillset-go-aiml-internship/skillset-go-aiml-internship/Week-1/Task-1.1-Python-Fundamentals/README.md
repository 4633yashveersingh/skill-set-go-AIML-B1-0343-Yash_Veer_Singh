# Task 1.1 - Python Fundamentals

## Objective
Practice core Python: variables & data types, I/O, operators, conditions, loops, functions, lists/tuples/sets/dicts, strings, file handling, exceptions, and basic OOP -- solved through small original exercises, not copied examples.

## Tools Used
- Python 3
- VS Code / Jupyter / Pycharm
- Git

## Work Completed
 One small file/notebook per topic, each starting from a tiny example then original exercises
 Small utilities using conditions/loops (grade calculator, number analyzer, menu program, pattern generator)
 Functions for repeated logic with meaningful names and parameters
 A realistic mini problem using lists/dicts (student records, products, marks, transactions)
 Read/write a text or CSV file; deliberately test a missing file or invalid input
 At least one class with attributes and methods, with a note on why OOP fit here
 try/except for expected runtime errors without hiding unrelated bugs
