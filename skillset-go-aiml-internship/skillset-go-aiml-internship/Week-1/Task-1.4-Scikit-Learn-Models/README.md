# Task 1.4 - Two ML Models with Scikit-learn

## Objective
Run the full supervised-learning workflow for one regression task and one classification task: split, preprocess, train a baseline, evaluate, and inspect errors.

## Tools Used
- Python
- scikit-learn
- Pandas
- Jupyter Notebook

## Work Completed
Pick one regression task (numeric target) and one classification task (categorical target)

 Clean inputs, separate features/target, create a sensible train/test split
 
 Use a preprocessing Pipeline where it makes sense
 
Train a simple baseline before attempting improvements

 Regression: evaluate with MAE, RMSE/MSE, R-squared as appropriate
 
 Classification: accuracy plus precision/recall/F1 and a confusion matrix where useful
 
Inspect incorrect predictions and note what the model struggled with

Record dataset, preprocessing, model settings, metrics and assumptions for reproducibility
