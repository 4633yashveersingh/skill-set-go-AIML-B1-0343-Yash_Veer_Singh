## Objective

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Work Completed

- [ ] Inspect shape, columns, dtypes, sample rows, summary stats, missing-value counts
- [ ] Check duplicates and quality issues (impossible values, inconsistent text, bad types)
- [ ] For each missing-value case, decide remove/fill/other and write down the reasoning
- [ ] Standardize categories, clean text, convert dates, fix numeric types
- [ ] Explore key columns (distributions, category counts) and relationships (scatter/box/trend plots)
- [ ] Write a short interpretation under each important chart
- [ ] Save the cleaned dataset separately; never overwrite the raw file

## Deliverables
