## 🚀 Getting Started

Clone the repository:
```bash
git clone https://github.com/4633yashveersingh/skill-set-go-AIML-B1-0343-Yash_Veer_Singh.git
cd skill-set-go-AIML-B1-0343-Yash_Veer_Singh
```

Install dependencies:
```bash
pip install -r requirements.txt
```
> *Add a `requirements.txt` (numpy, pandas, matplotlib, seaborn, scikit-learn, jupyter, etc.) if you don't already have one — it makes the repo reproducible for reviewers.*

Run the notebooks:
```bash
jupyter notebook
```
Then open the relevant `Week-X/Task-X.X-.../` folder and run the `.ipynb` file for that task.
